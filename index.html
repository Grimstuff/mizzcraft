Mod Installation Guide

Server is on Minecraft 26.2 (Fabric). Client must match.

Download these:

  1. Java 25 (Temurin JRE): Required for Minecraft 26.2 and the Iris installer. Use Java 25+ (21 is too old for this version).
  2. Iris Installer 3.3.0: Installs Fabric + Iris + Sodium for 26.2 (Iris 1.11.2, Sodium 0.9.1).
  3. BSL Classic v10.0: Beautiful vanilla-style shaders. (OPTIONAL — needs a decent GPU.)
  4. Simple Voice Chat 2.6.21+26.2: Proximity voice (same version the server runs).

How to Install:

  1. Install Java, then run the Iris Installer. Choose Minecraft 26.2 and the Iris + Fabric option (not Quilt).
  2. Open the Minecraft Launcher → Installations → for the new Fabric/Iris profile click Folder / Open Installation Folder.


  3. Drop BSL_v10.0.zip into the shaderpacks folder (create the folder if needed).
  4. Drop voicechat-fabric-2.6.21+26.2.jar into the mods folder (alongside Iris/Sodium/Fabric API).
  5. Important: Launch with the Fabric / Iris 26.2 installation in the launcher dropdown — not vanilla.
  6. Join address: mizzcord.com

Alternative Easy Installer

New to MC? Don't want to install mods manually?

  1. Download and install CurseForge App
  2. Open the app and click "Minecraft" as your active game.
  3. Search Mizzcraft, install the pack built for 26.2.
  4. Click play! Server list should include mizzcord.com.
  5. (Shaders are off by default — enable BSL in video settings / shader packs if you want them.)
